# Community sharing draft — do not post without approval

AGENT//RECEIPT is an experimental developer beta for local authorization-to-outcome evidence around AI agent tool calls. It is useful for reviewers interested in MCP enforcement boundaries, signed evidence, independent verification, and honest `INDETERMINATE` outcomes.

Please read the limitations before trying it. The project does not use real payments, does not provide remote OAuth protection, and is not independently security audited. Feedback should focus on reproducibility, interoperability, threat-model gaps, and whether the evidence claims are precise.
