# LinkedIn draft — do not post without approval

I’ve prepared AGENT//RECEIPT as an experimental open-source developer beta for inspecting what an AI agent was authorized to do, what it actually invoked, and what outcome evidence exists.

It includes a local official MCP demo, signed portable evidence, an independent Python verifier, a small JavaScript SDK, and a React investigation workbench. The boundaries are explicit: no real transactions, no remote OAuth claim, no production key custody, and no independent security audit.

I’m looking for technical feedback on the evidence model, trust-anchor provisioning, replay behavior, and developer experience—not endorsements of production readiness.
